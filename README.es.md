# Everend Plugins

<a href="README.md">English</a>

Adaptadores runtime para motores de juego y otros entornos. Consumen paquetes exportados por PathBranching sin ser dueños del canon ni de la autoría.

## Estado actual

El repositorio contiene contratos y planificación. El primer adaptador Unity es un paquete UPM local en packages/com.everendforge.unity, con una proyección configurable para SINPO v0.1. Revisa su [guía de instalación](packages/com.everendforge.unity/README.md) y el [plan del puente Unity](docs/UNITY_LIVE_BRIDGE_PLAN.md).

## Objetivos

1. Unity
2. Godot
3. Unreal

La API runtime prevista carga el paquete, inicia una historia, consulta líneas y elecciones, selecciona rutas, maneja variables y permite guardar o restaurar el estado.
